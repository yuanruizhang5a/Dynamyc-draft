\section{Syntax, sorting, and substitution}\label{sec:syntax}

\subsection{Terms and the nine primitive formulas}
Raw terms have the grammar
\[
 t\bnf x\mid f(t_1,\ldots,t_n).
\]
The result sort of a variable is its declared sort, and that of a function
application is the function's result sort. A well-sorted application has
exactly the argument profile declared by $f$, with recursively well-sorted
arguments. Argument lists in the raw datatype may be malformed; the syntax
checks reject them at rule boundaries.
\sources{\rocq{Syntax.v}{term}, \rocq{Syntax.v}{term_sort},
  \rocq{Syntax.v}{term_wfb}, \rocq{Syntax.v}{term_sortedb_spec}}

Formulas and programs are mutually defined:
\begin{align*}
 A,B\bnf{}&\top\mid p(\vec t)\mid t=_s u\mid\neg A\mid A\land B
     \mid\forall x:s.\,A\\
     &\mid\Fst{A}\mid\Suf{A}{B}\mid\BoxP{\alpha}{A},\\
 \alpha,\beta\bnf{}&x:=t\mid A?\mid\alpha;\beta
     \mid\alpha\cup\beta\mid\alpha^*.
\end{align*}
These are exactly nine formula constructors and five program constructors.
The first-state operator, suffix operator, and box modality are primitive.
The test $A?$ accepts any well-formed formula, including temporal formulas;
it is not subject to the pure-body restriction on quantifiers.
\sources{\rocq{Syntax.v}{formula}, \rocq{Syntax.v}{program},
  \rocq{Syntax.v}{formula_shapeb}}

The explicit equality sort $s$ must match both operands. The convenience
function \code{Equal t u} chooses $s$ from $t$; it still fails the formula
check if $u$ has another sort. Assignment $x:=t$ requires
$\mathsf{sort}(x)=\mathsf{sort}(t)$.
\sources{\rocq{Syntax.v}{Equal}, \rocq{Syntax.v}{formula_sortedb},
  \rocq{Syntax.v}{program_sortedb}}

An abbreviation and its expansion are identical raw syntax, including for
equality, substitution, sorting, and rule matching. Different displayed
abbreviations can overlap: $A\lor B$ and $(\neg A)\to B$ expand to the same
formula. A local rule generator can therefore offer several named rules at
the same occurrence.

\subsection{The pure first-order fragment}
Pure formulas $P,Q$ are generated by
\[
 P,Q\bnf\top\mid p(\vec t)\mid t=_s u\mid\neg P
       \mid P\land Q\mid\forall x:s.\,P.
\]
Derived Boolean connectives and existential quantifiers stay in this fragment.
Purity is a grammatical property; sorting and arity correctness are separate
requirements. Every quantifier body in a well-formed LPL formula must be pure,
recursively. Thus $[\alpha](\forall x.P)$ is permitted, whereas
$\forall x.[\alpha]P$ is rejected, even if $x$ is unused.
\sources{\rocq{Syntax.v}{pure_formula}, \rocq{Syntax.v}{pureb_spec},
  \rocq{Syntax.v}{formula_wfb}, \rocq{Syntax.v}{formula_wfb_spec}}

\subsection{Named, capture-avoiding substitution}
Term substitution $t[u/x]$ is structural. Formula substitution $P[t/x]$ is
the public \code{subst_fo} operation on the pure fragment. It stops beneath
a binder for $x$. At a different binder $y$, it first renames $y$ if that
name occurs in $t$, choosing a fresh name of the same sort, and then recurses.
Fresh names exceed all numerical names in the finite avoidance list. Bound
names are included in that list.
\sources{\rocq{Syntax.v}{subst_term}, \rocq{Syntax.v}{subst_fo},
  \rocq{Syntax.v}{fresh_variable}, \rocq{Syntax.v}{fresh_variable_not_in}}

For example, when $x,y,z$ have the same sort and $z$ is fresh,
\[
 (\forall y.\,p(x,y))[y/x]=\forall z.\,p(y,z).
\]
The raw helper \code{raw_subst_fo} does not perform this renaming; its semantic
law needs the explicit no-capture condition \code{free_forb}. Neither
operation is a general substitution mechanism for programs and temporal
formulas: their nonpure constructors are left unchanged by the FOL helper.
\sources{\rocq{Syntax.v}{raw_subst_fo}, \rocq{Syntax.v}{free_forb},
  \rocq{Semantics.v}{raw_subst_correct}}

\begin{proposition}[Preservation]
If $P$ is well formed, $t$ is well formed, and
$\mathsf{sort}(t)=\mathsf{sort}(x)$, then $P[t/x]$ is well formed. If $P$ is
pure, then $P[t/x]$ is pure. Renaming does not change a binder's sort.
\end{proposition}
\sources{\rocq{Syntax.v}{subst_fo_wf}, \rocq{Syntax.v}{subst_fo_pure}}

\begin{lemma}[Semantic substitution]
For a pure $P$ and any state $s$,
\[
 s\sat_{\mathrm{FO}} P[t/x]
 \quad\Longleftrightarrow\quad
 s[x\leftarrow\eval{t}{s}]\sat_{\mathrm{FO}}P.
\]
Here $\eval{t}{s}$ is an envelope, as in Section~\ref{sec:signature}.
\end{lemma}
\sources{\rocq{Semantics.v}{eval_term_subst}, \rocq{Semantics.v}{subst_fo_correct}}

\begin{proof}[Proof sketch]
Term substitution follows by structural recursion. For pure formulas, the
quantifier case commutes writes to distinct variables. A conflicting binder
is first renamed using the proved alpha-conversion law. A size bound makes
the source's fuel-based substitution sufficient for every recursive call.
\end{proof}
