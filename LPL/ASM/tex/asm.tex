\begin{abstract}
This manual documents the finite ASM layer in
\nolinkurl{Rocq-copy/LPL/ASM}. State descriptions contain only propositions;
transitions carry ordinary LPL instructions. Deductions open one state at a
time using a caller-supplied continuation and checked cyclic backlinks.
The reference explains the one-step interface, well-formedness and local
safety proofs, all-depth continuation contracts and five benchmark units.
Declaration links and a checked source snapshot connect the presentation
to the implementation.
\end{abstract}
