\subsection{Rebuilding and keeping the reference aligned}
The main document is \code{lpl.tex}; \code{setup.tex} contains typography and
theorem environments; \code{lpl.sty} supplies reusable mathematical notation.
Each substantive section has its own input file. All files needed for the
manual are in this directory; no Iris files are imported.

The local \code{Makefile} runs source-reference checks and builds the PDF.
The Python checker validates the declarations named by every
\code{\rocq} reference, verifies the input/label/reference structure, and
compares the current source hashes with \code{sources.json}.
\code{DECLARATIONS.md} provides source-line links for all referenced names.
After a theory change, review affected definitions, side conditions, ordered
premises, tags, and rank claims before explicitly refreshing the snapshot.
Hash equality and name existence detect drift; they do not establish the
mathematical correctness of a paraphrase.

The documentation checks are independent of compiling the Rocq theory.
The existing LPL build and validation commands remain documented in the
parent README. Build artifacts and a compilation log are kept locally;
the manual provides no file-deleting cleanup target.
